# Theme Enhancement and i18n Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thiện bộ token theme (Font tiếng Việt, layout tokens, CSS variables Tailwind v4) và tích hợp hệ thống đa ngôn ngữ (i18n) bằng React Context/Hook nội bộ với lưu trữ Cookie & LocalStorage.

**Architecture:** Sử dụng React 19 Context để cung cấp `I18nProvider` và hook `useTranslation()`. Từ điển được phân chia theo locale JSON files (`vi.json`, `en.json`). Theme được hoàn thiện thông qua cập nhật tokens và CSS variables tương thích với Tailwind CSS v4 `@theme inline`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS v4.

## Global Constraints
- Next.js 16.4.2 App Router, TypeScript strict mode.
- Tiếng Việt mặc định (`vi`), hỗ trợ chuyển đổi sang Tiếng Anh (`en`).
- Không đổi cấu trúc URL đường dẫn.
